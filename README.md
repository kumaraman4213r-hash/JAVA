# JAVA

A Java learning repository containing day-wise practice programs covering core Java concepts, object-oriented programming, and beginner-level exercises.

## Overview

The repository is organized into folders by lesson day. Each folder contains small Java source files demonstrating concepts and examples.

Topics represented in the source files include:

- Java basics, data types, and operators
- Type conversion and type promotion
- Conditional statements and switch statements
- `for`, `while`, and `do-while` loops
- Classes, objects, and methods
- Method overloading
- Arrays, multidimensional arrays, and enhanced `for` loops
- Strings
- Encapsulation and constructors
- Static members and anonymous objects
- Inheritance, `super`, and method overriding
- Packages and access modifiers
